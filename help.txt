Export the entire document.
 When using "--output-file", only a single input file can be specified.
 The export format will be recognized from the file extension of the output file.
 When using "--output-format", the file name and path of the rnote file is used with the extension changed.
 "--output-file and "--output-format" are mutually exclusive and specifying one of them is required

Usage: rnote-cli export doc [OPTIONS] <--output-file <OUTPUT_FILE>|--output-format <OUTPUT_FORMAT>> [RNOTE_FILES]...

Arguments:
  [RNOTE_FILES]...
          The rnote save file

Options:
  -o, --output-file <OUTPUT_FILE>
          The export output file. Exclusive with "--output-format"

  -f, --output-format <OUTPUT_FORMAT>
          The export output format. Exclusive with "--output-file"
          
          [possible values: svg, pdf, xopp]

      --page-order <PAGE_ORDER>
          The page order when documents with layouts that expand in horizontal and vertical directions are cut into pages

          Possible values:
          - horizontal-first: Split in row-major order
          - vertical-first:   Split in column-major order
          
          [default: horizontal-first]

      --on-conflict <ON_CONFLICT>
          The action that will be performed if the to be exported file(s) already exist(s)

          Possible values:
          - ask:       Ask before overwriting
          - overwrite: Overwrite existing files
          - skip:      Skip the export
          - suffix:    Append a number as a suffix to the file name
          
          [default: ask]

  -b, --no-background
          Export without background

  -p, --no-pattern
          Export without background pattern

      --optimize-printing
          Optimize the background and stroke colors for printing

      --open
          Inspect the result after the export is finished.
           Opens output folder when using "doc-pages" sub-command

  -h, --help
          Print help (see a summary with '-h')
