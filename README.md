# RNote Obsidian Plugin

A seamless integration with [RNote](https://github.com/flxzt/rnote). RNote is an open-source vector-based drawing app for sketching, handwritten notes, and annotations.

## Features

-   Automatically **export** RNote notes **to PDF/SVG** whenever they are modified (depends on your choice of configuration), so that they can be linked, embedded, and viewed in Obsidian
-   Easily **create** new RNote files (`.rnote`) directly from within Obsidian, accessible from the ribbon icon, file explorer, and command palette
-   Access the **"Edit in RNote"** option via an icon in the PDF preview as well as in file explorer, enabling quick navigation to the corresponding RNote file.

## Usage

> [!IMPORTANT]
> Be mindful that any PDF files sharing the same name and location as RNote (`.rnote`) files will be overwritten with the exported version if auto-export is enabled. This ensures seamless integration and consistent file management within Obsidian (regular vault backups are therefore recommended).

1. Ensure you have [RNote](https://github.com/flxzt/rnote) installed on your device
2. Configure the plugin settings with your RNote executable path.
